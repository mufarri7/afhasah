# الخصوصية

صُممت النسخة الأولى لتعمل دون حساب مستخدم أو قاعدة بيانات أو تحليلات تتبع.

- لا تطلب المنصة الاسم أو رقم الهاتف أو رقم IMEI.
- تُحفظ حالة الفحص مؤقتًا في ذاكرة الصفحة أثناء الاستخدام.
- عند مشاركة تقرير، تُرمّز بيانات الطراز والشبكة وإجابات الفحص وتوضع بعد علامة `#` في الرابط. هذا الجزء لا يُرسل إلى خادم الاستضافة في طلب الصفحة.
- يستطيع كل من يملك رابط التقرير قراءة محتواه؛ لذلك ينبغي مشاركته مع الأشخاص المقصودين فقط.
- يخزن عامل الخدمة ملفات التطبيق الثابتة على الجهاز ليعمل بعد التحميل دون اتصال.

لا ينبغي إدخال أي بيانات شخصية أو كلمات مرور أو رموز تحقق في حقول المنصة.
