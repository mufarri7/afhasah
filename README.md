# افحصه

افحص الهاتف قبل أن تدفع.

«افحصه» أداة عربية تنظم فحص الهاتف المستعمل على أرض الواقع، ثم تنشئ تقريرًا واضحًا ومؤرخًا يمكن مشاركته مع البائع أو المشتري. لا تحاول الأداة تخمين سلامة الجهاز من اسمه؛ كل نتيجة مرتبطة باختبار نفّذه المستخدم فعلًا.

## النسخة الأولى

- إدخال رقم الطراز الدقيق مع تعريف مجموعة أولية من نسخ Samsung وiPhone.
- اختبار الشريحة والمكالمات وبيانات الهاتف وVoLTE عمليًا.
- فحص الشاشة واللمس والكاميرات والصوت والشحن والأزرار والبصمة وسجل القطع.
- بوابة تسليم للحسابات وقفل التنشيط وإدارة المؤسسات وقفل التمويل.
- تقرير مؤرخ قابل للمشاركة أو الطباعة.
- واجهة عربية من اليمين إلى اليسار تعمل بعد التحميل دون اتصال.
- لا تسجيل، ولا قاعدة بيانات، ولا طلب لرقم IMEI.

## التشغيل محليًا

يتطلب Node.js 22 أو أحدث.

```bash
npm start
```

ثم افتح `http://127.0.0.1:4173`.

## التحقق

```bash
npm run check
npm test
```

## حدود واضحة

التقرير يوثق الاختبارات المنفذة وقت الفحص، ولا يعد شهادة ضمان أو إثبات ملكية. تطابق الترددات وحده لا يثبت عمل VoLTE؛ الاختبار الفعلي بالشريحة هو المرجع في هذه النسخة.

اقرأ [منهجية الفحص](docs/METHODOLOGY.md) و[سياسة الخصوصية](docs/PRIVACY.md) قبل المساهمة.
